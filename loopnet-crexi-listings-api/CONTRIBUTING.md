# Contributing

This repo is for examples, workflows, sample schemas, and integration help around the Commercial Real Estate Brokerage Intel Apify Actor.

It does not contain the private Actor source code. Issues and pull requests
should focus on integrations, documentation, sample output, and reusable
workflows.

Good issues:

- request a new example
- report a broken snippet
- suggest a better column order for broker review
- share a workflow for Google Sheets, CRM, Airtable, Make, Zapier, or a data warehouse

Please do not post private API tokens, private listing data, or personal contact data in issues.
